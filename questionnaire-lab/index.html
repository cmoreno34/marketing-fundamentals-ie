1The decision

If nothing would be done differently depending on the answer, the survey is not worth running. Write that first, then who you will ask.

2What you need to learn

Three things, no more. For each one, choose the table it will end up in: that is what stops a questionnaire from growing, and it also decides how the question has to be written. Pick one and read the line underneath: it tells you what that analysis is and what the question needs to look like. A line with no table does not become a question.

The rule behind this stepEvery question maps to one thing you need to learn and one analysis. If you cannot name the table, the question is not ready.

Copy it into Claude, ChatGPT or Gemini. What comes back is a draft: you cut it to the number of questions you asked for, and you check it against the faults of the test.
